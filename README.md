# Tap de Homebrew de Ecuafact

Fórmulas de [Homebrew](https://brew.sh) para instalar el CLI `ecuafact` en macOS y Linux.

```bash
brew tap ecuanexus/ecuafact
brew install ecuafact-preview
ecuafact --version
```

Actualizar: `brew upgrade ecuafact-preview`. Desinstalar: `brew uninstall ecuafact-preview`.

Documentación del CLI: <https://docsapi.ecuafact.com/v1/guias/cli>.
